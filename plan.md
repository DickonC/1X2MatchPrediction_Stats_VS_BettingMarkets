# 1X2 – Project Plan

**Task:** predict the full-time result `FTResult` ∈ {H, D, A} of a Premier League match **using only information available before kick-off** (3-class classification).

**Research question (draft):** *How well do pre-match features (Elo, recent form, head-to-head, lagged match stats) predict results, and do they add anything beyond the bookmaker's odds?* (coursework suggested question 3)

**Data:** [Club-Football-Match-Data](https://github.com/xgabora/Club-Football-Match-Data) cloned into `data_raw/` (commit `25882a5`). Raw files are never edited.

**Split (by season):** train 2005/06–2022/23 · validation 2023/24 · test 2024/25 + 2025/26
