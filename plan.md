# 1X2 – Project Plan

**Task:** predict the full-time result `FTResult` ∈ {H, D, A} (1X2) of a Premier League match **using only information available before kick-off** (3-class classification).

**Research question:** *Can pre-kick-off information predict EPL results, and does adding bookmaker (market) information improve predictive performance?* Based on coursework suggested question 3. See `AMLGroupProposal.pdf` (progress report, Nov 2026).

**Data:** [Club-Football-Match-Data](https://github.com/xgabora/Club-Football-Match-Data) in `data_raw/` (git submodule, commit `25882a5`). Raw files are never edited.

**Split (by season):** train 2005/06–2022/23 (6,840) · validation 2023/24 (380) · **test 2024/25 + 2025/26 (760)**. The test set is ready and hasn't been touched.

**Final report due:** Thu 26 Nov 2026, 12pm (4 pages + appendix).

## Step 3 at a glance
**Feature sets** (defined in `src/feature_sets.py`):
- `non_market` (9): AwayElo, EloDiff, Form5Diff, Home/Away Avg5 shots for/against, Home_Avg5_TargetFor, Home_H2H_GDPG
- `market` (3): ProbHome, ProbDraw, MaxOver25
- `combined` (12): both. **EloDiff added back** (changed from Step 2's 11-feature AM set, agreed 2026-11-17)

**Models:** logistic regression, random forest, KNN, each trained on all 3 sets (9 models).
**Baselines:** Always-Home, Bookmaker implied probabilities.
**Metrics:** accuracy, macro F1, log loss, multiclass Brier, multiclass ROC-AUC (OvR macro). Exact definitions are in the Step 3 file.
